---
name: code-illustration
description: Pages that need imagery when no image files are available. Draw illustrations, icons and textures with SVG and CSS.
---
- Prefer inline SVG for hero illustrations, icons and decorative shapes: crisp at every size, small, styleable with the page's tokens.
- Build illustrations from a few bold, layered shapes in the brand palette with one highlight colour, rather than many thin details. Give them depth with two or three tones of the same hue.
- Icons: one consistent set drawn on a 24 px grid with the same stroke width (1.5 or 2) and round joins. Never mix icon styles or use emoji as icons.
- Textures: subtle noise or grain with an SVG feTurbulence filter at low opacity, soft blobs with radial gradients, patterns with repeating SVG.
- Product or object shots can be suggested with CSS: layered gradients, a soft floor shadow, a highlight streak.
- Give every meaningful SVG role="img" and a <title>; mark decorative ones aria-hidden="true".
- Do not reproduce a real company's logo, mascot or trademarked artwork; use the brand's name in type and an original mark.
- Never hotlink images from other sites. If a real photo is essential, leave a clearly named placeholder file path and say so in the summary.
