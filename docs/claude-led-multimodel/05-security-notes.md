# ملاحظات سياسة الأمان

يوفر `packages/claude-led-orchestrator/src/security-policy.ts` حواجز صلاحيات أولية قابلة للاختبار على مستوى المنسّق. السياسة تمنح كل مهمة قائمة قراءة وقائمة كتابة مستقليْن للمسارات النسبية، وقائمة سماح لأسماء البرامج، مع قائمة منع مضمّنة وقائمة منع اختيارية لكل مهمة. لا يُسمح للمهمة بالوصول إلى مسارات مهمة أخرى، ولا تتجاوز صلاحية الكتابة صلاحية القراءة أو العكس.

## ما الذي تمنعه السياسة؟

- تُرفض ملفات `.env` ومتغيراتها (`.env.*` و`.envrc`)، ومجلدات اعتماد شائعة مثل `.ssh` و`.aws` و`.kube`، وملفات بيانات الاعتماد والأسرار والمفاتيح الخاصة وشهادات/حاويات المفاتيح الخاصة، وملفات Terraform state.
- يُرفض المسار المطلق أو مسار Windows أو أي مسار يحوي مقطع `..` أو NUL. يمكن لقواعد المسارات منح ملف بعينه أو مجلد فرعي باستخدام `dir/` أو `dir/**`.
- يجب تمرير الأمر كمتجه argv ذي اسم برنامج مجرد، وليس كنص shell. لا بد من وجود البرنامج في قائمة السماح، وتظل الأوامر الممنوعة مرفوضة حتى لو أُدرجت في قائمة السماح. تشمل أمثلة المنع shell وأدوات حذف/تغيير صلاحيات/شبكات وأوامر npm لتنفيذ السكربتات أو التثبيت، وبعض خيارات node وعمليات git عالية الأثر.

ينبغي للمنسّق استدعاء `authorizeFileAccess` قبل كل قراءة أو كتابة، و`authorizeCommand` قبل كل تنفيذ. يجب تمرير argv المعتمد مباشرة إلى واجهة إنشاء العملية مع `shell: false`؛ لا تحوّله إلى نص shell ولا تعِد تقسيمه.

## الحدود المهمة

> هذه السياسة ليست sandbox كاملة، ولا تنشئ عزلاً لنظام الملفات أو العمليات.

هي فحوصات قرار ساكنة في التطبيق فقط. لا تفتح الملفات ولا تنفذ الأوامر ولا تفرض القرار بذاتها؛ يمكن لأي مستدعٍ أن يتجاوزها إذا لم يلتزم باستدعائها عند كل نقطة وصول. وفحص المسار نصي لا يحل الروابط الرمزية ولا يحمي من سباقات TOCTOU أو من اختلافات نظام الملفات. يجب على طبقة التنفيذ استخدام جذر عمل موثوق، والتحقق من المسار الفعلي/الروابط الرمزية (بأسلوب مقاوم للسباق)، وفرض الصلاحيات عند فتح الملف.

قائمة السماح لأسماء البرامج لا تثبت أن البرنامج أو نسخته أو وسيطاته آمنة: قد يكون الملف التنفيذي الذي يحلّه PATH غير موثوق، وقد يشغّل البرنامج المسموح شيفرة أو إضافات أو خطافات أو سكربتات، وقد تسمح وسيطاته بآثار جانبية غير مغطاة بالقواعد الحالية. قواعد denylist تخفيف للمخاطر وليست تحليلاً دلالياً عاماً لكل CLI، كما أن تصنيف أسماء الأسرار لا يكتشف كل تنسيق أو اسم مخصص. لا توفر هذه الوحدة عزل شبكة، أو حدود موارد/وقت، أو حماية من kernel، أو منعاً لتسريب أسرار موجودة في الذاكرة أو البيئة أو سجلات التنفيذ.

للمهام غير الموثوقة أو الأوامر التي قد تتلف بيانات، استخدم بالإضافة إلى ذلك sandbox/حاوية أو VM مع مستخدم محدود وجذر ملفات مقيد، وبيئة نظيفة بلا أسرار، وقيود شبكة وموارد، ومهلات تنفيذ، وسجل تدقيق. اختبر إنفاذ التفويض في موضع الوصول الفعلي ولا تعتبر نجاح اختبارات هذه الوحدة دليلاً على عزل النظام.
