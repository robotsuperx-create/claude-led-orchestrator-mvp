# كتالوج بحث: مهارات ووكلاء UI/UX مفتوحة المصدر

**تاريخ التحقق: 5 أكتوبر 2026.** بحثت الويب وGitHub، وفتحت README ومهارات المصدر ذات الصلة، وملفات الرخصة الفعلية، وصفحات commits لكل مرشح. ترتيب القائمة تحريري، ويراعي ملاءمة تصميم/بناء الواجهة، جودة التوثيق، النشاط الحديث، وضوح الرخصة وسهولة التثبيت في Claude أو وفق Agent Skills. أرقام القدرات أدناه هي ادعاءات README وليست نتائج اختبار مستقل.

## أفضل خمسة

### 1. [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) — أفضل مكتبة مرجعية لتوليد اتجاه تصميم

- **ما يقدمه:** بيانات قابلة للبحث عن الأساليب والألوان والخطوط والأنماط وإرشادات UX، مع إرشادات لأطر متعددة وCLI لتوليد/اختيار نظام تصميم. يذكر README 79 أسلوب UI قابلًا للبحث، 192 لوحة ألوان، 74 توليفة خطوط، 119 قاعدة UX، و22 مكدسًا تقنيًا.
- **الرخصة:** MIT، موجودة في [LICENSE](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/blob/main/LICENSE).
- **النشاط:** أحدث commit ظاهر في صفحة [التاريخ](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/commits/main) هو 3 أكتوبر 2026؛ نشاط حديث جدًا.
- **الدمج:** يشرح README تثبيت Claude Marketplace أو CLI، ويعدد أهدافًا تشمل Claude وCursor وCodex وGemini وغيرها، بالإضافة إلى مخرج عام `.agents/skills/`.
- **ما نأخذه:** فكرة «استخرج توصيات تصميم مرتبطة بنوع المنتج والمكدس» ومجموعة محدودة قابلة للاستعلام عن tokens/أنماط. اجعلها مصدر اقتراحات اختياريًا لا قالبًا إجباريًا.
- **مخاطر الدمج:** المستودع وCLI والبيانات أكبر من مهارة واحدة، وهناك تبعية Python لبعض أوامر البحث؛ كما قد تنتج كثرة الأنماط لوحات جاهزة/نمطيّة إذا لم تسبقها قراءة brief ونظام المشروع القائم. لا تستورد كامل المحتوى لمجرد تثبيت المهارة، وتحقق من مصدر/ترخيص الأصول أو البيانات المنقولة بشكل منفصل عن رخصة الكود.

### 2. [UX/UI Agent Skills من plugin87](https://github.com/plugin87/ux-ui-agent-skills) — حزمة متكاملة مع ضوابط قابلة للاختبار

- **ما يقدمه:** تعليمات وtokens ومكوّنات وإرشادات وصول ومهارات تشغيلية ومراجعة نقدية. يعرض README 19 مهارة وعمليات مراجعة/gates، ويذكر DTCG وWCAG 2.2، وأمثلة تقييم وملفات اختبارات ونتائج تشغيل.
- **الرخصة:** MIT؛ النص في [LICENSE](https://github.com/plugin87/ux-ui-agent-skills/blob/main/LICENSE).
- **النشاط:** أحدث commit ظاهر في [سجل commits](https://github.com/plugin87/ux-ui-agent-skills/commits/main) بتاريخ 16 سبتمبر 2026، مع تغييرات حديثة نسبيًا على قواعد الفحص والتجارب.
- **الدمج:** يوفر Claude Code plugin وCLI (`npx ux-ui-agent-skills`) وملفات skills؛ README يشرح إضافة أجزاء بدل تثبيت المجموعة كلها.
- **ما نأخذه:** نهج جعل الجودة قابلة للتحقق: قواعد واضحة، حالات اختبار، مراجعة ناقدة منفصلة، ورفض الادعاء بأن شيئًا فُحص إذا لم يُفحص. استعر تصميم gates صغيرة قابلة لإعادة التشغيل على الواجهات التي نبنيها.
- **مخاطر الدمج:** حزمة واسعة ذات افتراضات و«صوت تصميم» خاص؛ تثبيت كل شيء قد يكرر تعليمات `CLAUDE.md` ويزاحم قواعد المشروع أو يستهلك سياقًا. أرقام gates والتقييمات في README ادعاءات صاحب المشروع—شغّل الاختبارات بنفسك ولا تعتبرها ضمان جودة أو شهادة WCAG. راجع أي scripts/npm قبل تشغيلها.

### 3. [Anthropic Skills — `frontend-design`](https://github.com/anthropics/skills/tree/main/skills/frontend-design) — أفضل أساس مختصر للتوجيه البصري

- **ما يقدمه:** skill قصير ومنظم لتصميم واجهة ذات طابع مقصود بدل مظهر قوالب AI. يبدأ بفهم الموضوع، ثم خطة تصميم (ألوان، خطوط، تخطيط)، نقد الخطة مقابل brief، فالتنفيذ؛ يتناول كذلك الحركة، النصوص، responsive، التركيز المرئي وتقليل الحركة.
- **الرخصة:** ملف [`LICENSE.txt` داخل مجلد المهارة](https://github.com/anthropics/skills/blob/main/skills/frontend-design/LICENSE.txt) يحدد Apache-2.0. لا تفترض أن رخصة واحدة تغطي كل المستودع؛ README يقول إن كثيرًا من مهاراته مفتوحة المصدر وبعضها source-available فقط، لذا تحقق من ملف كل مهارة قبل النسخ.
- **النشاط:** GitHub API يعرض `pushed_at` للمستودع بتاريخ 3 أكتوبر 2026، وصفحة [تاريخ commits](https://github.com/anthropics/skills/commits/main) تظهر commits منشورة حتى 29 سبتمبر؛ أحدث تعديل وجدته لمهارة `frontend-design` نفسها هو 3 سبتمبر 2026.
- **الدمج:** مستودع رسمي لمهارات Claude، بصيغة `SKILL.md`، مع تعليمات Claude Code plugin موثقة في [README](https://github.com/anthropics/skills/blob/main/README.md). بنية المهارة صغيرة ويسهل تكييفها إلى Agent Skills.
- **ما نأخذه:** إجراء «خطة → فحص التفرّد مقابل brief → بناء → نقد بصري»، وقاعدة ألا تُفرض زخارف/ألوان/بطاقات افتراضية دون مبرر، مع عناية بحالات الاستخدام وإمكانية الوصول.
- **مخاطر الدمج:** المهارة دليل أسلوبي وليست نظام تصميم أو ضمانًا للنتيجة؛ بعض توجيهاتها رأيية وقد تتعارض مع طلب عميل أو هوية قائمة، التي يجب أن تتقدم عليها. احتفظ بـApache LICENSE والاعتمادات وإشعار التعديل عند إعادة التوزيع، ولا تعمم ترخيص هذه المهارة على بقية مجلدات Anthropic.

### 4. [MengTo/Skills](https://github.com/MengTo/skills) — سير عمل للاستلهام من المراجع وتحويلها لمواصفات

- **ما يقدمه:** مكتبة واسعة ومقسمة لفئات، فيها مهارات UI وweb design، وأدوات لتحويل فيديو/صفحة مرجعية إلى prompt، التقاط الصفحة كاملة، دراسة التفاعلات، واستلهام يومي. يوثق README بنية `SKILL.md` والملفات المساندة وطرق الاستخدام في Codex وClaude وCursor.
- **الرخصة:** MIT، في [LICENSE](https://github.com/MengTo/skills/blob/main/LICENSE).
- **النشاط:** أحدث commit في [سجل commits](https://github.com/MengTo/skills/commits/main) هو 4 أكتوبر 2026؛ نشاط مستمر.
- **الدمج:** ملفات مهارات Markdown محمولة ويمكن تحميل المهارة المحددة مباشرة؛ README يشرح دعم عدة وكلاء ويشجع على استدعاء أضيق skill مناسب.
- **ما نأخذه:** نمط التقاط المرجع الكامل بدل الاكتفاء بصورة hero، وتوثيق التفاعل/الحركة كمدخل لإعادة تنفيذ أصيلة، مع حفظ prompts وdemos كملفات قابلة للمراجعة.

### 5. [Jakub Krehel Skills](https://github.com/jakubkrehel/skills) — مراجعة واجهة متعددة الأبعاد وأدوات تحسين مركزة

- **الرخصة:** MIT؛ النص في [LICENSE](https://github.com/jakubkrehel/skills/blob/main/LICENSE).
- **النشاط:** أحدث commit في [سجل commits](https://github.com/jakubkrehel/skills/commits/main) بتاريخ 29 أغسطس 2026.
- **الدمج:** يدعم `npx skills add jakubkrehel/skills` وClaude Code plugin؛ `SKILL.md` مقسم لمهارات منفصلة يمكن اختيارها.
- **ما نأخذه:** مراجعة محكومة بالنطاق والأدلة، قراءة تعليمات المشروع قبل الحكم، فصل أخطاء الاستخدام عن الذوق الشخصي، وتسجيل ما فُحص وما لم يُفحص. مفيد كـreview pass بعد البناء.
- **مخاطر الدمج:** رأي/عتبات بعض الفحوص قد لا تناسب كل منتج؛ لا تطبق skill المراجعة كقائمة ثابتة على كل الشاشات. شغّل فقط المجالات المناسبة، ولا تدّعِ مراجعة بصرية إن لم تُرَ الواجهة أثناء التشغيل.

## توصية التنفيذ

لا تثبّت الحزم الخمس معًا: هناك تداخل بين تعليمات التصميم وتدقيق الواجهة، وقد تتنافس على قرار الأسلوب أو تزيد سياق الوكيل. أنشئ مهارة محلية واحدة بصيغة Agent Skills/`SKILL.md` لتكون المنسّق، ومرّرها بهذا التسلسل:

1. اكتشاف brief وهدف المستخدم، ثم قراءة stack وtokens/components الحالية قبل اقتراح بدائل.
2. وضع اتجاه بصري ومجموعة tokens مختصرة خاصة بالمنتج؛ استدعِ بيانات Pro Max فقط عند الحاجة.
3. التنفيذ مع احترام الهوية، RTL عند اللزوم، responsive، حالات المكوّنات والوصول.
4. فحص النتيجة المرئية ثم مراجعة evidence-based؛ استعر أسلوب الخطة/النقد من Anthropic، وأدوات المراجعة من Jakub، وgates محدودة من plugin87.
5. أضف مسار MengTo فقط عندما يكون المدخل مرجعًا بصريًا/فيديو؛ لا تجعله جزءًا إلزاميًا من كل مهمة.

ابدأ بمقارنة قصيرة وتجربة داخلية بين **Anthropic `frontend-design` + مهارة مراجعة مختارة من Jakub**، وأضف من Pro Max مجموعة توصيات صغيرة بعد تثبيت هوية المنتج. جرّب ضوابط plugin87 على مجموعة صفحات ممثلة قبل اعتماد أي gate في CI. عند إعادة استخدام ملفات فعلية: ثبّت commit محددًا، احتفظ بنص الرخصة والإسناد (MIT أو Apache-2.0)، سجل المصدر والتعديلات، وافحص الأصول الخارجية والسكريبتات. أضف اختباراتنا الخاصة؛ لا تعتمد على أسماء المهارات أو أرقام README بديلًا عن معاينة بشرية وفحوص آلية مناسبة.
